🛡️ Backup e ripristino / Sauvegarde et restauration

🛡️ Backup e ripristino

Crea una copia di sicurezza di immagini personali, frasi e storie. Il file viene salvato sul tuo computer e puoi usarlo per ripristinare i dati.

La verifica controlla il file senza leggere o modificare i dati salvati nel browser.
Il test isolato crea un archivio temporaneo distinto, legge i dati ripristinati e poi lo elimina. Non modifica le tue storie o preferenze.
Consiglio: conserva una copia del backup anche su una chiavetta USB o in uno spazio sicuro.
